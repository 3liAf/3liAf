### About

Four years building things that make money move — analytics for SaaS and fintech, forecasting and pricing for e-commerce, and now AI automation as a product. Currently reading for an **M.Sc. in Artificial Intelligence** in Germany while running **Astrameld**, where I ship LLM agents, RAG pipelines and workflow automation for teams that would rather not do the boring 40% by hand.

I like problems where the answer is a number, and systems that survive their first real user.

```
building     →  Astrameld · AI automation, agents, RAG
working in   →  Python · TypeScript · SQL · AWS
thinking about →  MLOps, evaluation, vector search at scale
open to      →  freelance, collaboration, hard problems
```
